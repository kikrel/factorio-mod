ОЛЕГ 1.0.1 — БАЗОВАЯ РАБОЧАЯ ВЕРСИЯ
=========================================

Это намеренный откат к проверенной связке 0.3.3.
В этой версии НЕ добавляются глаза, память или строительство.

Задача версии:
- проверить стабильный чат;
- проверить нормальную русскую кириллицу;
- не менять работающий UDP/HTTP/кодировочный путь.

После успешного теста будем добавлять функции по одной.

Установка:
1. Закрой Factorio.
2. Удали предыдущую версию Олега из mods.
3. Положи ZIP мода в Factorio/mods.
4. Параметр запуска Factorio:
   --enable-lua-udp=38766
5. Запусти start_oleg.bat.
6. Вставь API key.
7. Запусти Factorio.
8. Открой Олега и напиши: привет

Если русский текст снова нормальный — база подтверждена.
