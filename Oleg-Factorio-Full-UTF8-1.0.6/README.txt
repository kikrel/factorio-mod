Олег ДЛЯ FACTORIO — ПОЛНАЯ ВЕРСИЯ 1.0.6

Содержимое:
- oleg_ai_1.0.2/ (мод Factorio)
- bridge.ps1 — мост с явной поддержкой UTF-8 без BOM
- start_oleg.bat — запуск с установкой кодовой страницы 65001

Установка:
1) Закройте Factorio.
2) Скопируйте папку oleg_ai_1.0.2 в %APPDATA%\Factorio\mods или распакуйте архив.
3) В параметрах запуска Factorio добавьте: --enable-lua-udp=38766
4) Запустите start_oleg.bat и введите API key (не публикуйте).
5) Запустите игру и проверьте чат Олега.
