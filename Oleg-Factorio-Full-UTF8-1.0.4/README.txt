ОЛЕГ ДЛЯ FACTORIO — ПОЛНАЯ ВЕРСИЯ 1.0.4

Содержимое:
- oleg_ai_1.0.2.zip — мод Factorio.
- start_oleg.bat — запуск bridge.
- bridge.ps1 — bridge с рабочим HTTP-профилем и явным UTF-8 ответом API.

Установка:
1. Закрой Factorio.
2. Скопируй oleg_ai_1.0.2.zip в %APPDATA%\Factorio\mods.
3. В параметрах запуска Factorio добавь: --enable-lua-udp=38766
4. Запусти start_oleg.bat и введи API key.
5. Запусти новую игру или перезагрузи сохранение с включённым модом.
6. Нажми кнопку «Олег» вверху экрана и напиши сообщение.

Bridge слушает 127.0.0.1:38767. API key не хранится в файлах.
